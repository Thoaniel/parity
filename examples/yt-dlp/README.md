# yt-dlp in Rust: Parity's flagship

The goal: a Rust `yt-dlp` that behaves exactly like the Python one, proven case by case.

- `cases.toml`: 270 cases. 59 written by hand cover output templates, filename sanitising, format selection
  and sorting, listings, JSON dumps and match filters. 211 generated by `parity discover` run every flag that
  takes no value.
- `info.json`: a synthetic video description with seven formats (no real media, no third-party data). Hand-written
  cases load it with `--load-info-json`, so every case runs offline.
- `corpus/`: what yt-dlp 2026.08.19 did in each case, recorded by `parity record` in the sandbox (no network).
- `ledger.toml`: every flag and source function of yt-dlp (301 flags, 4823 functions, mostly extractors) with
  its verdict.

```sh
parity replay -C examples/yt-dlp --candidate ./my-yt-dlp   # check any implementation
parity rewrite -C examples/yt-dlp                            # or let an agent write one in rewrite/
```

Network extraction (YouTube first) comes next, recorded against yt-dlp's own extractor test definitions; recordings
of third-party media are never committed.
